# Níveis de sentido

**Em uma linha:** a unidade de sentido não é a palavra — e tentar resolver teologia no nível do vocábulo sobrecarrega o vocábulo até ele quebrar.

> ⚠️ Não confundir com os **níveis N1–N5** de [[os-quatro-eixos]]. Aqueles medem o quanto uma *afirmação* cola no texto. Estes descrevem em que *unidade linguística* o sentido se forma.

| Nível | Responde |
|---|---|
| **Palavra** | O campo semântico — o que o termo pode significar |
| **Oração** | O que está sendo **afirmado** — sujeito, verbo, objeto, subordinação |
| **Parágrafo** | O argumento, a progressão, a estrutura |
| **Livro** | O propósito, o gênero, o destinatário |
| **Cânon** | Como isso se costura no todo da Escritura |

## A demonstração

Em Gênesis 1.1, o peso teológico foi atribuído por muito tempo à palavra *bereshit*, como se ela significasse "início absoluto de tudo".

Não significa. *Re'shit* é "a cabeça de", "a primeira parte de" — o termo comum para as **primícias** da colheita (Lv 23.10) e para o começo de um reino (Gn 10.10). A forma idêntica *bere'shit* aparece em Jr 26.1 significando apenas "quando começou o reinado de Jeoiaquim".

Quem carrega o peso são os outros níveis:

| Afirmação | Nível que a sustenta |
|---|---|
| "Houve um primeiro ato" | **Oração** — 1.1 é frase independente, não temporal subordinada |
| "Nada além de Deus é eterno" | **Cânon** — `Cl 1.16`; `Hb 11.3`; `Jo 1.3` |

A palavra abre uma lacuna — "na cabeça de ___" — e quem preenche é o objeto do verbo.

# Onde a briga não está

**Em uma linha:** o consenso sobre o léxico é largo — as disputas moram um degrau acima, quase sempre.

Quem quer "buscar na fonte" costuma esperar que o original resolva as controvérsias. Ele resolve poucas — mas o que ele entrega é sólido, e o padrão é consistente.

## O padrão, em Gênesis 1

| Palavra | Consenso lexical | Onde começa a briga |
|---|---|---|
| *bara* | Só Deus como sujeito no qal. **Ninguém discorda** | Se isso implica criação do nada — **teologia** |
| *yom* | Significa "dia". **Ninguém discorda** | Qual o referente aqui — **sintaxe e gênero** |
| *raqia* | Raiz de "bater metal até estender". **Ninguém discorda** | Se descreve abóbada sólida — **cosmologia antiga** |
| *tselem / demut* | "Imagem" e "semelhança". **Ninguém discorda** | O que é ser imagem de Deus — **doutrina** |
| *re'shit* | "Cabeça de", "primeira parte". **Ninguém discorda** | Se 1.1 é frase ou oração temporal — **sintaxe** |

Cinco palavras, cinco brigas, **nenhuma delas no léxico**.

## O que isso significa para o método

**Boa notícia:** o nível mais consensual da Escritura é acessível a quem não sabe hebraico, em minutos, de graça. Ver [[conferir-sem-hebraico]].

**Notícia que é a mesma:** por isso o léxico não decide teologia. Ver [[niveis-de-sentido]].

> A fonte vai dizer sempre a mesma coisa: **menos do que você esperava, e com muito mais firmeza.**

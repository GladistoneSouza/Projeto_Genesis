# As três perguntas

**Em uma linha:** duas seções podem parecer se contradizer sem se contradizer — e podem se contradizer de verdade escondidas atrás de "são coisas diferentes". O que separa os dois casos é dizer **a que pergunta cada uma responde**.

Toda vez que o comentário fala do mundo antigo, três perguntas estão na mesa. Cada uma tem **uma** resposta.

| | Pergunta | Tipo | Onde se decide |
|---|---|---|---|
| **P1** | O que o leitor antigo **imaginava**? | Histórica | Texto, versões antigas, Antigo Oriente |
| **P2** | O que **existe de fato**? | Científica | Fora do comentário |
| **P3** | O que o texto **afirma**? | Teológica | `posicoes.md`, com fatura |

## A proibição

**Descrição de P1 não usa conhecimento posterior.**

Se a seção conta como o israelita via o mundo, ela não pode descrever o que física, química, astronomia e meteorologia levaram milênios para estabelecer. Isso não é ser científico — é **pôr palavras na boca de um morto**, e ainda apresentá-las como se fossem o sentido do versículo.

## O caso que gerou a régua

`05-dias-1-3` §5.4 glosava o segundo dia assim:

> "a expansão entre as águas superiores **(nuvens, chuva)** e as águas inferiores (mares)… águas acima → firmamento **(céu/atmosfera)** → águas abaixo"

Nuvem e atmosfera são resposta de **P2**. Estavam escritas como se fossem **P1** — como se fosse o que "águas superiores" significa no texto.

Enquanto isso, `09-antigo-oriente` §5.9 dizia, corretamente, que o *raqia* reflete "a cosmologia do mundo antigo, onde o céu era concebido como uma estrutura sólida".

**As duas seções pareciam brigar. Só uma estava errada** — e não por discordar da outra, mas por responder a pergunta errada.

## O sintoma

**Ter de trocar de modelo no meio.**

O mesmo §5.4, três blocos adiante, explicava `Gn 7.11` com "as comportas dos céus" — que só funcionam no quadro antigo. Nuvem não tem comporta.

> Seção que responde P1 de forma coerente não precisa pegar emprestado o mobiliário de P2. Quando o empréstimo acontece, **o modelo abandonado é o que estava certo para aquela faixa.**

## O que a régua não faz

Não decide P3. Ela **limpa a mesa** para que P3 possa ser decidida: enquanto P1 e P2 estiverem misturadas, qualquer posição teológica estará respondendo a uma pergunta mal formulada.

E não manda esconder a divergência. **P1 e P2 divergirem é o esperado** — o problema é o comentário fingir que não divergem, pelos dois lados: nem harmonizar o texto antigo com a ciência, nem tratar a ciência como se o texto a estivesse contestando.

# PWA estática — Projeto Gênesis

Esta pasta é a versão mobile-first do leitor. Ela não precisa de `server.mjs`: lê o `main` público do próprio repositório diretamente pelo GitHub.

- `index.html`: casca da interface
- `app.js`: consulta HEAD/árvore/raw do GitHub e renderiza o vault
- `styles.css`: visual mobile-first
- `manifest.webmanifest` + `sw.js`: PWA
- `icon.svg`: ícone provisório

O conteúdo continua em `Projeto Genesis/Projeto Genesis/` e não é duplicado aqui.
